# v2026.318.0

> 发布日期：2026-03-18

## 亮点

- **插件框架和 SDK** — 完整的插件系统，带运行时生命周期管理、CLI 工具、设置 UI、面包屑和插槽可扩展性、领域事件桥，以及一个 kitchen-sink 示例。插件 SDK 现在包括文档 CRUD 方法和测试工具。（[#904](https://github.com/paperclipai/paperclip/pull/904)、[#910](https://github.com/paperclipai/paperclip/pull/910)、[#912](https://github.com/paperclipai/paperclip/pull/912)、[#909](https://github.com/paperclipai/paperclip/pull/909)、[#1074](https://github.com/paperclipai/paperclip/pull/1074)、@gsxdsm、@mvanhorn、@residentagent）
- **升级的成本和预算** — 改进的成本跟踪和预算管理界面。（[#949](https://github.com/paperclipai/paperclip/pull/949)）
- **Issue 文档和附件** — Issue 现在支持内联文档编辑、创建前的文件暂存、深度链接文档、复制和下载操作，以及实时事件刷新。（[#899](https://github.com/paperclipai/paperclip/pull/899)）
- **Hermes 智能体适配器** — 新的 `hermes_local` 适配器为 Hermes CLI 作为智能体后端提供支持。（[#587](https://github.com/paperclipai/paperclip/pull/587)、@teknium1）
- **执行工作区（实验性）** — 智能体运行的隔离执行工作区，包括工作区操作跟踪、可重用工作区去重和工作产品管理。项目级工作区策略可配置。（[#1038](https://github.com/paperclipai/paperclip/pull/1038)）
- **心跳 token 优化** — 心跳周期现在跳过冗余的 token 使用。

## 改进

- **会话压缩是适配器感知的** — 压缩逻辑现在尊重每个适配器的上下文限制。
- **公司标志** — 上传和显示公司标志，带 SVG 清理和增强的安全头以获取资产响应。（[#162](https://github.com/paperclipai/paperclip/pull/162)、@JonCSykes）
- **应用版本标签** — 侧边栏现在显示运行中的 Paperclip 版本。（[#1096](https://github.com/paperclipai/paperclip/pull/1096)、@saishankar404）
- **项目选项卡缓存** — 记住每个项目的活动项目选项卡；选项卡已重命名和重新排序。（[#990](https://github.com/paperclipai/paperclip/pull/990)）
- **Issue 复制到剪贴板** — Issue 详情 header 现在包含复制按钮；HTML 实体不再泄漏到复制的文本中。（[#990](https://github.com/paperclipai/paperclip/pull/990)）
- **我和未分配 assignee 选项** — 当前用户和未分配 issue 的快速筛选 assignee 选项。（[#990](https://github.com/paperclipai/paperclip/pull/990)）
- **在新 issue 对话框中跳过预填充字段** — 当 assignee 和项目字段已填充时，Tab 顺序现在跳过它们。（[#990](https://github.com/paperclipai/paperclip/pull/990)）
- **Worktree 清理命令** — 新的 `worktree:cleanup` 命令、环境变量默认值和 worktree 分支的自动前缀。（[#1038](https://github.com/paperclipai/paperclip/pull/1038)）
- **发布自动化** — 带 npm 信任发布和来源元数据的自动化金丝雀和稳定发布工作流。（[#1151](https://github.com/paperclipai/paperclip/pull/1151)、[#1162](https://github.com/paperclipai/paperclip/pull/1162)）
- **文档链接** — 侧边栏文档链接现在指向外部 docs.paperclip.ing。
- **入门启动任务延迟** — 启动任务不再在用户启动之前创建。

## 修复

- **嵌入式 PostgreSQL 强化** — 启动采用、数据目录验证和 UTF-8 编码现在可靠处理。（@vkartaviy）
- **`os.userInfo()` 防护** — 仅使用 UID 的容器不再崩溃；HOME 被排除在缓存键之外。（[#1145](https://github.com/paperclipai/paperclip/pull/1145)、@wesseljt）
- **opencode-local HOME 解析** — `os.userInfo()` 用于模型发现，而不是依赖 HOME 环境变量。（[#1145](https://github.com/paperclipai/paperclip/pull/1145)、@wesseljt）
- **dotenv cwd 回退** — 当 `.paperclip/.env` 缺失时，服务器现在从 `cwd` 加载 `.env`。（[#834](https://github.com/paperclipai/paperclip/pull/834）、@mvanhorn）
- **插件事件订阅接线** — 修复了订阅清理、过滤器可空性和过时图表。（[#988](https://github.com/paperclipai/paperclip/pull/988)、@leeknowsai）
- **插件插槽渲染** — 纠正了插件 UI 扩展的插槽注册和渲染。（[#916](https://github.com/paperclipai/paperclip/pull/916)、[#918](https://github.com/paperclipai/paperclip/pull/918)、@gsxdsm）
- **归档项目 UX** — 归档现在导航到仪表板并显示 toast；用内联确认替换了 `window.confirm`。
- **Markdown 编辑器间距** — 图片拖放/粘贴添加正确的换行符；标题顶部边距增加。
- **工作区表单刷新** — 当通过 URL 键访问项目时，表单现在刷新，允许空保存。
- **旧迁移协调** — 修复了现有安装的迁移协调。
- **`archivedAt` 类型强制** — 在 Drizzle 更新之前进行字符串到 Date 的转换以防止类型错误。
- **智能体 HOME 环境变量** — `AGENT_HOME` 现在正确为子智能体进程设置。（[#864](https://github.com/paperclipai/paperclip/pull/864)）
- **侧边栏滚动条悬停轨道** — 修复了悬停时滚动条轨道的可见性。（[#919](https://github.com/paperclipai/paperclip/pull/919)）
- **非配置选项卡上的粘性保存栏** — 隐藏以防止布局推送。
- **空目标显示** — 从空目标中移除"None"文本。
- **运行页面填充** — 移除了不必要的右填充。
- **Codex 引导日志** — 当作 stdout 而不是 stderr 处理。
- **开发运行器语法** — 修复了插件开发运行器中的语法问题。（[#914](https://github.com/paperclipai/paperclip/pull/914）、@gsxdsm）
- **进程列表** — 修复了进程列表渲染。（[#903](https://github.com/paperclipai/paperclip/pull/903）、@gsxdsm）

## 升级指南

十个新的数据库迁移（`0028`–`0037`）将在启动时自动运行：

- **迁移 0028–0029** 添加插件框架表。
- **迁移 0030–0037** 扩展了 issue 文档、执行工作区、公司标志、成本跟踪和插件增强的模式。

所有迁移都是增量的（新表和列）— 不修改现有数据。标准 `paperclipai` 启动将自动应用它们。

如果你使用 `.env` 文件，请注意，当 `.paperclip/.env` 未找到时，服务器现在回退到从当前工作目录加载 `.env`。
