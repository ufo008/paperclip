# v0.2.7

> 发布日期：2026-03-04

## 改进

- **入门弹性** — 设置向导现在在环境测试失败后继续，而不是卡住。如果你的 Anthropic API 密钥不工作，你可以重试或清除它，然后用不同的配置继续。
- **Docker 入门流程** — Docker 冒烟测试的更清洁默认值，以及 `npx` 入门运行期间改进的控制台指导。
- **技能中的 Issue 搜索** — Paperclip 技能引用现在记录了 `q=` 搜索参数，用于按关键字查找 issue。

## 修复

- **Markdown 列表渲染** — 修复了列表标记（`-`、`*`）在编辑器和评论视图中不正确渲染的问题。
- **归档公司隐藏** — 新 issue 对话框不再在公司选择器中显示归档的公司。
- **嵌入式 Postgres 要求** — 服务器现在在嵌入式 DB 模式下正确要求 `embedded-postgres` 依赖，防止启动失败。
