# v0.3.1

> 发布日期：2026-03-12

## 亮点

- **Gemini CLI 适配器** — 对 Google Gemini CLI 的完整本地适配器支持。包括 API 密钥检测、轮次限制处理、沙盒和审批模式、技能注入到 `~/.gemini/`，以及 yolo 模式默认。（[#452](https://github.com/paperclipai/paperclip/pull/452)、[#656](https://github.com/paperclipai/paperclip/pull/656)、@aaaaron）
- **运行转录优化** — 运行转录渲染 markdown、折叠命令 stdout、编辑家庭路径和用户身份，并在详情和实时界面上显示人性化的事件标签。（[#648](https://github.com/paperclipai/paperclip/pull/648)、[#695](https://github.com/paperclipai/paperclip/pull/695)）
- **收件箱改进** — 改进了选项卡行为、徽章计数与可见未读项目对齐、更好的移动布局，以及更流畅的新 issue 提交状态。（[#613](https://github.com/paperclipai/paperclip/pull/613)）
- **改进了入门向导** — 入门现在显示 Claude Code 和 Codex 作为推荐适配器，折叠其他类型，并具有带可点击选项卡的动画步骤转换。适配器环境检查在成功时动画，仅在失败时显示调试输出。（[#700](https://github.com/paperclipai/paperclip/pull/700)）

## 改进

- **实例心跳设置侧边栏** — 直接从实例设置页面查看和管理心跳配置，带紧凑的分组成运行列表。（[#697](https://github.com/paperclipai/paperclip/pull/697)）
- **项目和智能体配置选项卡** — 用于项目和智能体的新选项卡配置 UI，包括执行工作区策略设置。（[#613](https://github.com/paperclipai/paperclip/pull/613)）
- **智能体运行选项卡** — 智能体详情页面现在包括专用运行选项卡。
- **可配置的附件内容类型** — `PAPERCLIP_ALLOWED_ATTACHMENT_TYPES` 环境变量让运营商控制可以上传的文件类型。（[#495](https://github.com/paperclipai/paperclip/pull/495)、@subhendukundu）
- **默认最大轮次提高到 300** — 智能体现在默认 300 最大轮次，而不是之前的限制。（[#701](https://github.com/paperclipai/paperclip/pull/701)）
- **Issue 创建者显示在侧边栏** — issue 属性面板现在显示每个 issue 的创建者。（[#145](https://github.com/paperclipai/paperclip/pull/145)、@cschneid）
- **公司感知 404 处理** — UI 现在显示公司范围的 not-found 页面，而不是通用错误。
- **开发者 Worktree 工作流工具** — 新的 `paperclipai worktree:make` 命令提供隔离的开发实例，带自己的数据库、secrets、favicon 品牌和 git hooks。Worktree 支持最小种子模式、起点选择和自动工作区重新绑定。（[#496](https://github.com/paperclipai/paperclip/pull/496)、[#530](https://github.com/paperclipai/paperclip/pull/530)、[#545](https://github.com/paperclipai/paperclip/pull/545)）

## 修复

- **Gemini Docker 构建** — 在 Docker deps 阶段包含 Gemini 适配器清单，以便生产构建成功。（[#706](https://github.com/paperclipai/paperclip/pull/706)、@zvictor）
- **审批重试幂等性** — 重复的审批提交不再创建重复记录。（[#502](https://github.com/paperclipai/paperclip/pull/502)、@davidahmann）
- **心跳成本记录** — 成本现在通过 `costService` 路由，而不是内联记录，修复了缺失的成本归属。（[#386](https://github.com/paperclipai/paperclip/pull/386)、@domocarroll）
- **Claude Code 环境变量泄漏** — 子适配器进程不再继承 Claude Code 的内部环境变量。（[#485](https://github.com/paperclipai/paperclip/pull/485)、@jknair）
- **`parentId` 查询筛选器** — issue 列表端点现在正确应用 `parentId` 筛选器。（[#491](https://github.com/paperclipai/paperclip/pull/491)、@lazmo88）
- **移除 `Cmd+1..9` 快捷键** — 公司切换键盘快捷键与浏览器选项卡切换冲突，已移除。（[#628](https://github.com/paperclipai/paperclip/pull/628)、@STRML）
- **IME 组合 Enter** — 在 IME 组合期间按 Enter 不再过早移动焦点。（[#578](https://github.com/paperclipai/paperclip/pull/578)、@kaonash）
- **主机名更改后重启提示** — CLI 现在在更改允许的主机名后提醒用户重启服务器。（[#549](https://github.com/paperclipai/paperclip/pull/549)、@mvanhorn）
- **无人值守智能体的默认 `dangerouslySkipPermissions`** — 没有终端运行的智能体现在默认为跳过权限提示，而不是挂起。（[#388](https://github.com/paperclipai/paperclip/pull/388)、@ohld）
- **从 OpenClaw Gateway 移除过时的 `paperclip` 属性** — 清理了导致警告的无效智能体参数。（[#626](https://github.com/paperclipai/paperclip/pull/626)、@openagen）
- **Issue 描述溢出** — 长描述不再破坏布局。
- **Worktree JWT 持久性** — 环境敏感的 JWT 配置现在正确地进入到 worktree 实例中。
- **开发迁移提示** — 修复了本地开发的嵌入式 `db:migrate` 流程。
- **Markdown 链接对话框定位** — 链接插入对话框不再渲染在屏幕外。
- **漂亮的日志元数据** — 服务器日志元数据保持在一行而不是换行。

## 升级指南

两个新的数据库迁移（`0026`、`0027`）将在启动时自动运行：

- **迁移 0026** 添加了 `workspace_runtime_services` 表，用于 worktree 感知的运行时支持。
- **迁移 0027** 向 issue 添加 `execution_workspace_settings`，向项目添加 `execution_workspace_policy`。

两者都是增量的（新表和新列）— 不修改现有数据。标准 `paperclipai` 启动将自动应用它们。
