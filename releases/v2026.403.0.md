# v2026.403.0

> 发布日期：2026-04-03

## 亮点

- **收件箱大修** — 新的"我的"收件箱选项卡，带邮件客户端键盘快捷键（j/k 导航、a/y 归档、o 打开）、滑动归档、"全部标记为已读"按钮、带键盘控制的运营搜索，以及"今日"分隔线。已读/忽略状态现在扩展到所有收件箱项目类型。（[#2072](https://github.com/paperclipai/paperclip/pull/2072)、[#2540](https://github.com/paperclipai/paperclip/pull/2540)）
- **反馈和评估** — 点赞/点踩反馈捕获流程，带投票 UI、反馈模态框样式，以及反馈行中的运行链接放置。（[#2529](https://github.com/paperclipai/paperclip/pull/2529)）
- **文档修订** — Issue 文档修订历史，带恢复流程、重放安全迁移和修订跟踪 API。（[#2317](https://github.com/paperclipai/paperclip/pull/2317)）
- **遥测** — 匿名化的应用端遥测。使用 `DO_NOT_TRACK=1` 或 `PAPERCLIP_TELEMETRY_DISABLED=1` 禁用（[#2527](https://github.com/paperclipai/paperclip/pull/2527)）
- **执行工作区（实验性）** — 智能体运行的完整工作区生命周期管理：支持工作区的 routine 运行、带链接 issue 的执行工作区详情页面、运行时控制（启动/停止）、关闭就绪检查，以及后续 issue 工作区继承。项目工作区获得自己的详情页面和项目视图上的专用选项卡。（[#2074](https://github.com/paperclipai/paperclip/pull/2074)、[#2203](https://github.com/paperclipai/paperclip/pull/2203)）

## 改进

- **评论中断** — 新的 issue 评论中断支持，带排队的评论线程 UX。
- **Docker 改进** — 改进的基础镜像组织、卷挂载的主机 UID/GID 映射，以及 Docker 文件结构。（[#2407](https://github.com/paperclipai/paperclip/pull/2407)、[#1923](https://github.com/paperclipai/paperclip/pull/1923)、@radiusred）
- **乐观评论** — 评论在服务器确认时即时渲染，带乐观 ID；修复了草稿清除，提供了更流畅的撰写体验。
- **GitHub Enterprise URL 支持** — 技能和公司导入现在接受 GitHub Enterprise URL，强化了 GHE URL 检测和共享 GitHub 辅助函数。（[#2449](https://github.com/paperclipai/paperclip/pull/2449)、@statxc）
- **Gemini 本地适配器** — 在适配器类型验证枚举中添加了 `gemini_local`，因此 Gemini 智能体不再验证失败。（[#2430](https://github.com/paperclipai/paperclip/pull/2430)、@bittoby）
- **Routines 技能** — 新的 `paperclip-routines` 技能，文档移至 Paperclip 引用。Routine 运行现在支持工作区感知和变量。（[#2414](https://github.com/paperclipai/paperclip/pull/2414)、@aronprins）
- **GPT-5.4 和 xhigh effort** — 为基于 OpenAI 的适配器添加了 GPT-5.4 模型回退和 xhigh effort 选项。（[#112](https://github.com/paperclipai/paperclip/pull/112)、@kevmok）
- **提交指标** — 新的 Paperclip 提交指标脚本，带筛选导出和边缘情况处理。
- **CLI 入门** — 入门重新运行现在保留现有配置；导出的 tsx CLI 入口点实现更清洁的启动。（[#2071](https://github.com/paperclipai/paperclip/pull/2071)）
- **Board 委派指南** — Board 运营者委派模式的新文档。（[#1889](https://github.com/paperclipai/paperclip/pull/1889)）
- **组织结构图中的智能体能力** — 智能体能力字段现在在组织结构图卡片上渲染。（[#2349](https://github.com/paperclipai/paperclip/pull/2349)）
- **PR 模板更新** — 在 PR 模板中添加了 Model Used 部分；CONTRIBUTING.md 现在要求 PR 模板、Greptile 5/5 和测试。（[#2552](https://github.com/paperclipai/paperclip/pull/2552)、[#2618](https://github.com/paperclipai/paperclip/pull/2618)）
- **Hermes 适配器升级** — 升级了 hermes-paperclip-adapter，支持 UI 适配器和技能，以及 detectModel 改进。
- **Markdown 编辑器等宽字体** — 智能体指令文件编辑器现在使用等宽字体。（[#2620](https://github.com/paperclipai/paperclip/pull/2620)）
- **Markdown 链接样式** — Markdown 中的链接现在带下划线和指针光标渲染。
- **@-提及自动完成** — 项目描述中的提及自动完成现在通过 portal 渲染以防止溢出裁剪。
- **跳过的唤醒消息** — 智能体详情视图现在显示跳过的唤醒消息以获得更好的可观察性。

## 修复

- **收件箱排序** — 自我触碰的 issue 不再沉到收件箱底部。（[#2144](https://github.com/paperclipai/paperclip/pull/2144)）
- **环境变量类型切换** — 从 Plain 切换到 Secret 不再丢失值；修复了切换时的下拉框回跳。（[#2327](https://github.com/paperclipai/paperclip/pull/2327)、@radiusred）
- **适配器类型切换** — 更改适配器类型时，适配器无关的密钥现在被保留。
- **项目 slug 冲突** — 非 ASCII 项目名称不再产生重复 slug；附加了短 UUID 后缀。（[#2328](https://github.com/paperclipai/paperclip/pull/2328)、@bittoby）
- **Codex RPC 生成错误** — 修复了 CodexRpcClient 在生成 Codex 时 ENOENT 崩溃。（[#2048](https://github.com/paperclipai/paperclip/pull/2048)、@remdev）
- **心跳会话重用** — 修复了心跳运行之间的过时会话重用。（[#2065](https://github.com/paperclipai/paperclip/pull/2065)、@edimuj）
- **反向代理下的 Vite HMR** — 修复了反向代理后面的 WebSocket HMR 连接，并添加了 StrictMode 防护。（[#2171](https://github.com/paperclipai/paperclip/pull/2171)）
- **复制按钮回退** — 复制到剪贴板现在在非安全（HTTP）上下文中工作。（[#2472](https://github.com/paperclipai/paperclip/pull/2472)）
- **Worktree 默认分支** — Worktree 创建在未配置 baseRef 时自动检测默认分支。（[#2463](https://github.com/paperclipai/paperclip/pull/2463)）
- **会话连续性** — 定时器和心跳唤醒现在保持会话连续性。
- **Worktree 隔离** — 修复了 worktree 供给隔离、运行时恢复和同级端口冲突。
- **Cursor 适配器认证** — Cursor 适配器现在在警告缺少 API 密钥之前检查原生认证。
- **Codex 技能注入** — 修复了技能注入，使用有效的 `$CODEX_HOME/skills/` 而不是 cwd。
- **OpenCode 配置污染** — 防止了工作区目录中的 `opencode.json` 配置污染。
- **Pi 适配器** — 修复了 Pi 本地适配器执行、转录解析和从 stderr 的模型检测。
- **x-forwarded-host 来源检查** — Board 变更来源检查现在包括 x-forwarded-host header。
- **健康数据库探测** — 修复了数据库连接健康检查探测。
- **Issue 面包屑路由** — 强化了 issue 面包屑来源路由。
- **指令选项卡宽度** — 移除了指令选项卡的 max-w-6xl 约束以实现全宽内容。（[#2621](https://github.com/paperclipai/paperclip/pull/2621)）
- **Windows 上的 Shell 回退** — 在 Windows 上使用 `sh` 而不是 `/bin/sh` 作为 shell 回退。（[#891](https://github.com/paperclipai/paperclip/pull/891)）
- **反馈迁移** — 在 rebase 后使反馈迁移重放安全。
- **Issue 详情优化** — 优化了 issue 详情时间线和附件显示。

## 升级指南

四个新的数据库迁移（`0045`–`0048`）将在启动时自动运行。这些迁移添加了工作区生命周期列、routine 变量、反馈表和文档修订跟踪。所有迁移都是增量的 — 不修改现有数据。

如果你使用执行工作区，请注意后续 issue 现在自动从其父级继承工作区链接。对于绑定到同一工作区的非子级后续 issue，在创建 issue 时明确设置 `inheritExecutionWorkspaceFromIssueId`。
