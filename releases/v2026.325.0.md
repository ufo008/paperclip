# v2026.325.0

> 发布日期：2026-03-25

## 亮点

- **公司导入/导出** — 完整的公司可移植性，带文件浏览器 UX 用于导入和导出智能体公司。包括丰富的 frontmatter 预览、嵌套文件选择器、合并历史支持、GitHub 简写引用和 CLI `company import`/`company export` 命令。导入的公司在导入后自动打开，默认禁用导入智能体的心跳计时器。（[#840](https://github.com/paperclipai/paperclip/pull/840)、[#1631](https://github.com/paperclipai/paperclip/pull/1631)、[#1632](https://github.com/paperclipai/paperclip/pull/1632)、[#1655](https://github.com/paperclipai/paperclip/pull/1655)）
- **公司技能库** — 新的公司范围技能系统，带技能 UI、所有本地适配器（Claude、Codex、Pi、Gemini）的智能体技能同步、带更新检查的固定 GitHub 技能，以及内置技能支持。（[#1346](https://github.com/paperclipai/paperclip/pull/1346)）
- **Routines 和周期性任务** — 完整的 routines 引擎，带触发器、routine 运行、合并和周期性任务可移植性。包括 API 文档和 routine 导出支持。（[#1351](https://github.com/paperclipai/paperclip/pull/1351)、[#1622](https://github.com/paperclipai/paperclip/pull/1622)、@aronprins）

## 改进

- **收件箱中的内联加入请求** — 加入请求现在与其他工作和项目一起内联渲染在收件箱中。
- **入门播种** — 在入门期间用目标上下文为新项目和 issue 播种，以获得更好的首次运行体验。
- **智能体指令恢复** — 托管的智能体指令在启动时从磁盘恢复；指令在适配器切换之间保留。
- **心跳设置页面** — 显示所有智能体，不受间隔配置影响；添加了"全部禁用"按钮用于快速批量控制。
- **通过参与实现的智能体历史** — 智能体 issue 历史现在使用参与记录而不是直接分配查询。
- **按字母顺序排序智能体** — 智能体按名称字母顺序在所有视图中排序。
- **公司组织结构图资产** — 改进了为公司生成的组织结构图可视化。
- **改进的 CLI API 连接错误** — 当 CLI 无法访问 Paperclip API 时显示更好的错误消息。
- **Markdown 提及链接** — Lexical LinkNode 中现在允许自定义 URL 方案，实现带正确链接行为的提及药丸。提及药丸的原子删除现在正确工作。
- **Issue 工作区重用** — 隔离运行后正确重用工作区。
- **失败运行会话恢复** — 现在可以通过 honor 标志恢复显式失败的运行会话。
- **Docker 镜像 CI** — 添加了 Docker 镜像构建和部署工作流。（[#542](https://github.com/paperclipai/paperclip/pull/542)、@albttx）
- **Issue 上的项目筛选器** — Issue 列表现在可以按项目筛选。（[#552](https://github.com/paperclipai/paperclip/pull/552)、@mvanhorn）
- **内联评论图片附件** — 上传的图片现在内联嵌入在评论中。（[#551](https://github.com/paperclipai/paperclip/pull/551)、@mvanhorn）
- **AGENTS.md 回退** — Claude-local 适配器在 AGENTS.md 缺失时优雅回退。（[#550](https://github.com/paperclipai/paperclip/pull/550)、@mvanhorn）
- **公司创建者技能** — 用于从头开始搭建智能体公司包的新技能。
- **报告页面重命名** — 为清晰起见重命名了报告部分。（[#1380](https://github.com/paperclipai/paperclip/pull/1380)、@DanielSousa）
- **Eval 框架引导** — 基于 Promptfoo 的评估框架，带用于系统化智能体行为测试的 YAML 测试用例。（[#832](https://github.com/paperclipai/paperclip/pull/832)、@mvanhorn）
- **Board CLI 认证** — 用于 CLI 的基于浏览器的认证流程，因此 board 用户可以在不手动复制 API 密钥的情况下进行认证。（[#1635](https://github.com/paperclipai/paperclip/pull/1635)）

## 升级指南

七个新的数据库迁移（`0038`–`0044`）将在启动时自动运行：

- **迁移 0038** 向心跳运行添加进程跟踪列（PID、开始时间、重试跟踪）。
- **迁移 0039** 添加 routines 引擎表（routines、triggers、routine runs）。
- **迁移 0040–0042** 扩展公司技能、周期性任务和可移植性元数据。
- **迁移 0043** 添加 Codex managed-home 和智能体指令恢复列。
- **迁移 0044** 添加 board API 密钥和 CLI 认证挑战表，用于基于浏览器的 CLI 认证。

所有迁移都是增量的（新表和列）— 不修改现有数据。标准 `paperclipai` 启动将自动应用它们。

如果你使用公司导入/导出功能，请注意导入的公司默认禁用心跳计时器。在验证适配器配置后，从心跳设置页面手动重新启用它们。
