# v0.3.0

> 发布日期：2026-03-09

## 亮点

- **新适配器：Cursor、OpenCode 和 Pi** — Paperclip 现在支持三个额外的本地编码智能体。Cursor 和 OpenCode 作为一流适配器集成，带模型发现、运行日志流式传输和技能注入。Pi 添加了带成本跟踪的本地 RPC 模式。所有三个都出现在入门向导中，与 Claude Code 和 Codex 并列。（[#62](https://github.com/paperclipai/paperclip/pull/62)、[#141](https://github.com/paperclipai/paperclip/pull/141)、[#240](https://github.com/paperclipai/paperclip/pull/240)、[#183](https://github.com/paperclipai/paperclip/pull/183)、@aaaaron、@Konan69、@richardanaya）
- **OpenClaw 网关适配器** — 新的仅网关 OpenClaw 流程替换了传统适配器。它使用严格的 SSE 流式传输，支持设备密钥配对，并处理带加入令牌验证的基于邀请的入门。（[#270](https://github.com/paperclipai/paperclip/pull/270)）
- **收件箱和未读语义** — Issue 现在跟踪每个用户的已读状态。未读指示器出现在收件箱、仪表板和浏览器选项卡（蓝点）中。收件箱徽章包括加入请求和审批，收件箱排序以警报为中心。（[#196](https://github.com/paperclipai/paperclip/pull/196)、@hougangdev）
- **PWA 支持** — UI 作为可安装的渐进式 Web 应用发货，带 service worker 和增强的清单。service worker 使用网络优先策略来防止过时内容。
- **智能体创建向导** — 新的选择模态和完整页面配置流程使添加智能体更容易。侧边栏 AGENTS header 现在有快速添加按钮。

## 改进

- **Markdown 中的 Mermaid 图表** — 围栏 `mermaid` 块在 issue 评论和描述中渲染为图表。
- **实时运行输出** — 运行详情页面通过 WebSocket 实时流式传输输出，带合并的增量去重的订阅源项目。
- **复制评论为 Markdown** — 每个评论 header 都有一键复制为 markdown 按钮。
- **重试失败的运行** — 失败和超时的运行现在在运行详情页面上显示重试按钮。
- **项目状态可点击** — 项目属性面板中的状态 chip 现在可点击以进行快速更新。
- **滚动到底部按钮** — 当你向上滚动时，issue 详情和运行页面显示浮动滚动到底部按钮。
- **数据库备份 CLI** — `paperclipai db:backup` 让你按需快照数据库，可选自动调度。
- **禁用注册** — 新的 `auth.disableSignUp` 配置选项（和 `AUTH_DISABLE_SIGNUP` 环境变量）让运营商锁定注册。（[#279](https://github.com/paperclipai/paperclip/pull/279)、@JasonOA888）
- **去重的短名称** — 智能体和项目短名称在创建和更新时自动去重，而不是拒绝重复。（[#264](https://github.com/paperclipai/paperclip/pull/264）、@mvanhorn）
- **人类可读的职位标签** — 智能体列表和属性面板显示友好的职位名称。（[#263](https://github.com/paperclipai/paperclip/pull/263）、@mvanhorn）
- **Assignee 选择器排序** — 最近的选择首先出现，然后按字母顺序。
- **移动布局优化** — 在 issue、收件箱和仪表板上统一 GitHub 风格的 issue 行。改进了弹出框滚动、命令面板居中和移动属性切换。（[#118](https://github.com/paperclipai/paperclip/pull/118）、@MumuTW）
- **邀请 UX 改进** — 邀请链接自动复制到剪贴板、设置中的仅代码片段流程、10 分钟邀请 TTL，以及更清晰的网络主机指导。
- **评论的永久链接锚点** — 每个评论都有稳定的锚点链接和 GET-by-ID API 端点。
- **Docker 部署强化** — 默认启用认证部署模式、命名数据卷、`PAPERCLIP_PUBLIC_URL` 和 `PAPERCLIP_ALLOWED_HOSTNAMES` 在 compose 文件中暴露、健康检查 DB 等待，以及 Node 24 基础镜像。（[#400](https://github.com/paperclipai/paperclip/pull/400)、[#283](https://github.com/paperclipai/paperclip/pull/283)、[#284](https://github.com/paperclipai/paperclip/pull/284)、@AiMagic5000、@mingfang）
- **更新的模型列表** — 在适配器模型常量中添加了 `claude-sonnet-4-6`、`claude-haiku-4-6` 和 `gpt-5.4`。（[#293](https://github.com/paperclipai/paperclip/pull/293)、[#110](https://github.com/paperclipai/paperclip/pull/110)、@cpfarhood、@artokun）
- **Playwright e2e 测试** — 涵盖入门向导流程的新端到端测试套件。

## 修复

- **运行日志中的秘密编辑** — 从 secrets 来源的环境变量现在按出处编辑，一致的 `secretKeys` 跟踪。（[#261](https://github.com/paperclipai/paperclip/pull/261）、@mvanhorn）
- **SPA catch-all 500** — 服务器在 catch-all 路由中提供缓存的 `index.html`，并在 `sendFile` 中使用 `root`，防止点文件路径和 SPA 刷新上的 500 错误。（[#269](https://github.com/paperclipai/paperclip/pull/269)、[#78](https://github.com/paperclipai/paperclip/pull/78）、@mvanhorn、@MumuTW）
- **未匹配的 API 路由返回 404 JSON** — 以前会直通到 SPA 处理程序。（[#269](https://github.com/paperclipai/paperclip/pull/269）、@mvanhorn）
- **智能体唤醒逻辑** — 智能体在 issue 移出积压时唤醒，在自己的评论上跳过自我唤醒，跳过积压状态更改的唤醒。待审批的智能体被排除在心跳计时器之外。（[#159](https://github.com/paperclipai/paperclip/pull/159)、[#154](https://github.com/paperclipai/paperclip/pull/154)、[#267](https://github.com/paperclipai/paperclip/pull/267)、[#72](https://github.com/paperclipai/paperclip/pull/72）、@Logesh-waran2003、@cschneid、@mvanhorn、@STRML）
- **运行日志 fd 泄漏** — 修复了日志追加中的文件描述符泄漏，导致 `spawn EBADF` 错误。（[#266](https://github.com/paperclipai/paperclip/pull/266）、@mvanhorn）
- **500 错误日志** — 错误日志现在包含实际错误消息和请求上下文，而不是通用的 pino-http 输出。
- **布尔环境解析** — `parseBooleanFromEnv` 不再将常见真值静默视为 false。（[#91](https://github.com/paperclipai/paperclip/pull/91）、@zvictor）
- **入门环境默认值** — `onboard` 现在正确地从环境变量派生 secrets，并在 `local_trusted` 模式下报告忽略的暴露设置。（[#91](https://github.com/paperclipai/paperclip/pull/91）、@zvictor）
- **Windows 路径兼容性** — 迁移路径使用 `fileURLToPath` 以实现 Windows 安全的解析。（[#265](https://github.com/paperclipai/paperclip/pull/265)、[#413](https://github.com/paperclipai/paperclip/pull/413)、@mvanhorn、@online5880）
- **HTTP 上的安全 cookie** — 为 plain HTTP 部署禁用安全 cookie 标志，以防止认证失败。（[#376](https://github.com/paperclipai/paperclip/pull/376）、@dalestubblefield）
- **URL 编码** — `buildUrl` 分割路径和查询以防止 `%3F` 编码问题。（[#260](https://github.com/paperclipai/paperclip/pull/260）、@mvanhorn）
- **认证信任来源** — 有效的信任来源和允许的主机名现在在公共模式下正确应用。（[#99](https://github.com/paperclipai/paperclip/pull/99）、@zvictor）
- **UI 稳定性** — 修复了提示模板清空时的空白屏幕、导致重新渲染的搜索 URL 同步、收件箱中的 issue 标题溢出，以及包括审批的侧边栏徽章计数。（[#262](https://github.com/paperclipai/paperclip/pull/262)、[#196](https://github.com/paperclipai/paperclip/pull/196)、[#423](https://github.com/paperclipai/paperclip/pull/423)、@mvanhorn、@hougangdev、@RememberV）
