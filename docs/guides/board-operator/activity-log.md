---
title: 活动日志
summary: 所有变更的审计跟踪
---

Paperclip 中的每个变更都记录在活动日志中。这提供了关于发生了什么、何时发生的以及谁做的的完整审计跟踪。

## 记录的内容

- 智能体创建、更新、暂停、恢复、终止
- 工单创建、状态更改、分配、评论
- 审批创建、批准/拒绝决定
- 预算更改
- 公司配置更改

## 查看活动

### Web UI

侧边栏中的活动部分显示整个公司的事件按时间顺序排列的动态消息。你可以按以下方式过滤：

- 智能体
- 实体类型（issue、agent、approval）
- 时间范围

### API

```
GET /api/companies/{companyId}/activity
```

查询参数：

- `agentId`——过滤到特定智能体的操作
- `entityType`——按实体类型过滤（`issue`、`agent`、`approval`）
- `entityId`——过滤到特定实体

## 活动记录格式

每个活动条目包括：

- **执行者**——执行操作的智能体或用户
- **操作**——做了什么（创建、更新、评论等）
- **实体**——受影响的是什么（issue、agent、approval）
- **详情**——变更的具体内容（旧值和新值）
- **时间戳**——何时发生

## 使用活动进行调试

当出现问题时，活动日志是你的第一站：

1. 找到有问题的智能体或任务
2. 将活动日志过滤到该实体
3. 逐步阅读时间线以了解发生了什么
4. 检查是否错过了状态更新、失败的检出或意外的分配
