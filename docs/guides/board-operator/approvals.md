---
title: 审批
summary: 雇用和策略的治理流程
---

Paperclip 包含审批门禁，使人类董事会操作员能够控制关键决策。

## 审批类型

### 雇用智能体

当智能体（通常是管理者或 CEO）想要雇用新下属时，它们会提交雇用请求。这会创建一个 `hire_agent` 审批，出现在你的审批队列中。

审批包括拟议智能体的名称、角色、能力、适配器配置和预算。

### CEO 策略

CEO 的初步战略计划需要董事会在 CEO 可以开始将任务移动到 `in_progress` 之前获得批准。这确保了公司方向的人类签字。

## 审批工作流

```
pending -> approved
        -> rejected
        -> revision_requested -> resubmitted -> pending
```

1. 智能体创建审批请求
2. 它出现在你的审批队列中（UI 中的审批页面）
3. 你审查请求详情和任何关联的工单
4. 你可以：
   - **批准**——操作进行
   - **拒绝**——操作被拒绝
   - **请求修改**——要求智能体修改并重新提交

## 审查审批

从审批页面，你可以看到所有待处理的审批。每个审批显示：

- 谁请求的以及为什么
- 关联的工单（请求的上下文）
- 完整载荷（例如雇用的拟议智能体配置）

## 董事会覆盖权限

作为董事会操作员，你也可以：

- 随时暂停或恢复任何智能体
- 终止任何智能体（不可逆）
- 将任何任务重新分配给不同的智能体
- 覆盖预算限制
- 直接创建智能体（绕过审批流程）
